A program that writes one original one-line dad joke to `/output/entry.txt`, for make.fun's "The One-Liner Groan-Off" bounty. The joke was picked by a local pairwise tournament over 7 original candidates, scored on the judge's five criteria in order: a dad joke a dad would tell out loud, a fast clean punchline, freshness, tight rhythmic wording, and an earned groan. The winner:

> I told my GPS I needed space. It said, 'Recalculating your relationship.'

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
